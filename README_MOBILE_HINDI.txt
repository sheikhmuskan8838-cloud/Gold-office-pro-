GOLD OFFICE PRO - Android project

Mobile se APK build karne ke liye:
1. ZIP extract karein.
2. github.com par New repository banayein, naam: GoldOfficePro
3. Repository ke andar project ke sabhi files/folders upload karein. ZIP file ko as-is upload na karein.
4. .github/workflows/android.yml file bhi upload honi chahiye.
5. Commit changes karein.
6. Repository > Actions kholein.
7. "Build GOLD OFFICE PRO APK" workflow select karke Run workflow dabayein.
8. Build complete hone par run ke andar Artifacts section se GOLD-OFFICE-PRO-debug-apk download karein.
9. ZIP artifact extract karein; app-debug.apk milega.

Note: This is an unsigned debug APK for testing. It contains general message/record organization only.
